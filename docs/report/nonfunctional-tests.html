Non-Functional Tests

Checks how well the app does it: fast enough, secure enough, accessible enough, under enough load. There are 16 test types here.

Accessibility testingAICHAT-10

WCAG checked on every page, light and dark theme.
Visual regression testingAICHAT-19

Pixel-diffed screenshots of key screens in both themes.
Performance testing (frontend)AICHAT-21

LCP, INP and CLS budgets per page, checked by Lighthouse CI.
Bundle size budget testingAICHAT-22

Each micro-frontend's shipped JS stays under its size budget.
Load testingAICHAT-24

Concurrent users and streams, ramped until the 4 GB VM saturates.
Dependency vulnerability scanning (SCA)AICHAT-6

Known CVEs in npm packages, kept patched by Dependabot.
Container image scanningAICHAT-7

Every image scanned for CVEs before it's pushed.
Prompt injection testingAICHAT-26

Malicious text hidden in a file or page can't change the app's behaviour.
SASTAICHAT-27

Static analysis on every pull request, a high finding blocks the merge.
DASTAICHAT-28

The deployed app attacked from the outside, weekly.
Penetration testingAICHAT-29

A manual, time-boxed attack of the deployed app.
SBOM generationAICHAT-30

A full, versioned dependency list for every shipped image.
Secret scanningAICHAT-31

No key or password ever committed, checked on every change.
PII masking testingAICHAT-32

Emails, IPs and message content checked across logs and telemetry.
GDPR retention and deletion testingAICHAT-33

Deleting a user removes their chats, files and telemetry, verified against a real database.
Coverage thresholdsAICHAT-34

A minimum line/branch coverage per project, enforced in CI.
