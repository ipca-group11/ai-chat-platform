The app under test

A chat application where a user signs up, logs in, adds their own API key for an AI provider (Anthropic or OpenAI), and chats with it. This includes attaching files and seeing replies stream in live.

The frontend is four micro-frontends (shell, auth, chat, settings) loaded together. The backend is two Node services (auth and conversations) behind an API.

A mock backend stands in for the real AI provider during tests, so nothing depends on a live key or costs anything to run.
