Security Non-functional Black-box
What it checks

The deployed app is attacked from the outside, the same way a real attacker would. No knowledge of the source code is used.

Tooling
  • OWASP ZAP baseline scan
Cadence

Weekly, against staging.

Full epic details, from Jira

Description

Dynamic Application Security Testing scans the app the way an attacker actually would - while it's running, not just by reading the source. This area uses OWASP ZAP against the live stack (the shell, each micro-frontend, the auth service and the conversation service) to catch problems that only show up at runtime: missing security headers, authentication that can be bypassed, information leaking out in responses, and the kind of API-level issues that only surface once requests are actually hitting the server.

Inputs
  • The running application stack, reachable over HTTP
  • A test account and session so scans can cover logged-in pages and APIs, not just public ones
  • The OpenAPI specs for the backend services
Acceptance Criteria
  • Every pull request gets scanned automatically against the running stack, and a high-severity finding blocks the merge.
  • Logged-in-only areas of the app, like chat and settings, get scanned with a real session, not just the public pages.
  • The app sends the security headers browsers expect, and a scan confirms they stay in place.
  • A deeper, scheduled scan tests the backend APIs directly against their documented endpoints, catching things a simple crawl would miss.
Tooling / Tech Stack
  • OWASP ZAP (baseline and active scan modes)
  • CI pipeline and the Docker Compose stack already used for end-to-end tests
  • OpenAPI specs as the source of truth for API scanning
Definition of Ready
  • A severity policy exists so the team agrees up front on what blocks a merge versus what's just reported.
Definition of Done
  • The baseline scan runs automatically on every pull request and a high-severity finding blocks it.
  • The scheduled, deeper API scan runs weekly against staging and files a ticket on anything high severity.
