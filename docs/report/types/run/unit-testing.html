How to run: Unit testing

View on Jira: AICHAT-17 ↗
No Docker needed
Terminal, from the repo root
# every project, with coverage thresholds
pnpm exec nx run-many -t test

# one project, e.g. mfe-chat, conversation-service
pnpm exec nx run <project>:test

# untested files vs the exempt list
node scripts/unit-test/source-files.ts --check
